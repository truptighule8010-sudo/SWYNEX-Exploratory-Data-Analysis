# SWYNEX Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a sales dataset using Python and Pandas.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Analysis Performed
- Data inspection
- Statistical analysis
- Category-wise Sales and Profit analysis
- Region-wise Sales and Profit analysis
- Product-wise Sales and Profit analysis
- Monthly Sales Trend
- Quantity analysis
- Data insights and observations

## Key Insights
- Electronics category generated the highest sales.
- Laptop was the highest-selling product by sales.
- West region recorded the highest sales.
- Sales varied across different months.
- The dataset contains 28 orders and 60 total units.
